# kubectl-mcp-server is pinned exactly, matching platformfix/podium's
# Dockerfile (confirmed working there 2026-09-03; re-confirmed directly
# against this repo's own kind cluster while building it) - so a new
# release can't introduce a break silently. Dependabot (pip ecosystem)
# opens a PR to review instead.
#
# fastmcp is allowed up to 4.x. kubectl-mcp-server 1.24.0 (still the
# latest release) only declares fastmcp>=3.0.0b1 and imports
# ToolAnnotations from fastmcp.tools, which fastmcp 4 removed - so under
# fastmcp 4 the tool fails to import and never starts. setup.sh rewrites
# that one import to mcp.types (the home fastmcp 4's upgrade guide names,
# and the fallback kubectl-mcp-server's own code already uses) right after
# this file is installed. Drop that step once kubectl-mcp-server ships a
# fastmcp 4 compatible release.
kubectl-mcp-server==1.24.0
fastmcp<5
